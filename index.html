WIT Job Monitor Drive Backup

This is a personal backup connection for the WIT job monitor. It copies the monitor's saved job posting history, trial results, and backup manifest between the owner's computer, Google Drive, and a private cloud runner. It does not offer public sign-in or access to anyone else's Drive.

The connection requests Google Drive access because the backup program reads and writes files in the owner's private “WIT job monitor data” folder. Google's authorization technically grants broader Drive access than that folder, although the program is configured to use that folder only.
